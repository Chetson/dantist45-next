# dantist45-next

Сайт стоматологии «Дантист» (Курган): Next.js 16, PostgreSQL, Prisma, Docker Compose.

```bash
git clone https://github.com/Chetson/dantist45-next.git && cd dantist45-next
cp .env.example .env          # заполнить переменные
docker compose up -d --build  # сайт на http://127.0.0.1:3000
```
